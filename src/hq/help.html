HQ recording — setup

HQ mode records the call audio and transcribes it with a local Whisper model. Quality is far better than platform captions, and audio never leaves your machine — the only network target is 127.0.0.1.

One-time setup (macOS)

  1. Install the engine: 
    brew install whisper-cpp
  2. Download the model and start the server (first download is ~1.6 GB): 
    mkdir -p ~/.sotto/models
curl -L -o ~/.sotto/models/ggml-large-v3-turbo.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
whisper-server -m ~/.sotto/models/ggml-large-v3-turbo.bin --host 127.0.0.1 --port 8123

    If you cloned the repo, use ./scripts/whisper-server.sh instead, and ./scripts/install-launchd.sh to start the server at login automatically (idle cost: ~1.8 GB RAM, zero CPU).

  3. On the first Start HQ a microphone-permission page opens — allow it, otherwise only the other side of the call is transcribed.

Recording

  1. Be on the call tab, open the Sotto popup.
  2. Pick the language (ru/en/auto) → Start HQ. The icon shows a green HQ badge.
  3. Entries appear with a 10–25 s delay — chunks are cut on silence. Your voice is labeled «Вы», the tab audio «Собеседник».
  4. Stop HQ when done — or just close the tab; the transcript saves automatically.

Troubleshooting

  • whisper-server not running — check curl http://127.0.0.1:8123/; launchd logs: ~/.sotto/logs/whisper-server.log.
  • No «Вы» entries — mic permission wasn't granted; start a recording and accept the page it opens.
